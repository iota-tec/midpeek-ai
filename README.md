vex-ai — Minimal Scaffold

This repository is a minimal starting point to turn long Valorant recordings into short highlight reels.

MVP ideas (not implemented yet):
- Audio-first: separate comms vs. game audio, transcribe, and find funny/exciting moments.
- Video-first: detect highlight-worthy plays from visual cues and motion.

Only basic directory structure and comment-only stubs are included to indicate intended purposes.
